# Projeto Integrador 3B — Fase I

Projeto de análise de uma rede de consumo modelada como grafo bipartido
entre usuários e produtos.

## Autores

- Yuri Victor
- Pedro Arthur
- Danielly Luz
- Gabriel Vieira Braga

## Estrutura do projeto

- `src/` — implementação dos algoritmos em C
- `dados/` — dataset e subamostras
- `scripts/` — execução automatizada dos experimentos
- `resultados/` — CSVs e gráficos gerados
- `artigo/` — artigo da Fase I

## Requisitos

Para compilar e executar os experimentos:

- GCC
- GNU Make
- Python
- matplotlib

No Windows, o projeto foi testado utilizando MSYS2 UCRT64.
